## 修复 GUI 两个 bug (Windows-Cleaner-Tools)

### Bug 1: 窗口显示不全
- 根因: 原窗体 700x580, 底部按钮 Y=524+28=552 超出可见区; 无 DPI 自适应, 高 DPI 下控件溢出裁切。
- 修复: 窗体改 720x640, 设 `AutoScaleMode=Dpi` + `AutoScaleDimensions=96,96` + `MinimumSize`; panel 420高, 进度条/日志框/按钮坐标整体下移 (进度470/日志490/按钮586), 全部在 640 内。

### Bug 2: 运行弹 PowerShell 窗口
- 根因: 双击 .ps1 由 powershell.exe 打开弹控制台; 原 `Restart-AsAdmin` 也未隐藏窗口。
- 修复: 新建 `启动清理工具.bat` 用 `powershell -WindowStyle Hidden -File` 启动 GUI; `Restart-AsAdmin` 加 `-WindowStyle Hidden` 与 `psi.WindowStyle=Hidden`。
- README/OPENSPEC 已补充启动器与 GUI 章节。

### 工具调用教训 (cmd 环境)
- shell 是 cmd 非 PowerShell: 跨盘用 `cd /d`, 不能用 Set-Location/cd 单参数。
- execute_command 对含 powershell 长命令常 skip; 改 `cmd /c "powershell -File 脚本.ps1"` 可行。
- write_to_file 用 UTF-8 存, GBK 乱码汉字会字节变化; 修 .bat 乱码改用读字节(GB18030)→按行号替换→写回, 不依赖乱码字面量。
